# ESP32 Stikka

Firmware with WebUI used on ESP32-S3 N16R8 module to connect to Stikka-MQTT


## Supported boards

* ESP32-S3 DevkitC-1 N16R8 (https://www.aliexpress.com/item/1005012092039320.html)

## Supported printers

| Printer | Method | Description |
|---|---|---|
| Zebra / ZPL | Network | Printer connected to the same network as the ESP32 (not recommendet)|
| Zebra / ZPL / ZPL | USB | Printer connected to the USB-B port of the printer | 
| Brother QL | USB | Printer connected to the USB-B port of the printer | 
| Seiko SPL | USB | Printer connected to the USB-B port of the printer |
